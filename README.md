# Qibla

An Arabic, right-to-left SwiftUI prototype for prayer times, Qibla direction, and app settings.

## Run

1. Open `Qibla.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Press **Run**.

The current prayer schedule, distance, and compass bearing intentionally match the supplied prototype and are static sample data.
